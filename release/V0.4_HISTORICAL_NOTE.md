# Communications v0.4 historical material

Annotated tag `communications-v0.4.0` is the exact immutable v0.4 release. Its source files, destination hashes, captured-tree regression fixture, deterministic materializer/verifier, containment prompts, and Git history remain available unchanged at that tag.

Some v0.4 files remain visible on current `main` for audit and reproducibility. They are historical, not current v0.5 operating instructions. In particular, v0.4's exact-tree contamination rule and mandatory clean-repository recovery are superseded. Under v0.5, evolution outside `.nx/` is sovereign and the separate credential review handles security concerns without issuing a global repository judgment.
